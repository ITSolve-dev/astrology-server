# Архитектурные правила

Базовые правила, нарушение которых недопустимо.

- **Роутер вызывает только сервис** — никаких обращений к репозиториям, UoW или домену напрямую
- **Сервис — чистый оркестратор** — не содержит бизнес-правил, вычислений и деталей хранилища
- **Единый язык обмена — доменные сущности** (dataclass) на всех слоях и между модулями
- **Module boundary** — модули импортируют друг друга только через `__init__.py`, прямой импорт из `internals/` другого модуля запрещён
- **Именование по назначению** — `users_repo.py`, `user_entity.py`, не `repository.py`, `entities.py`
- **Доменная модель не зависит от инфраструктуры** — маппинг таблиц зависит от домена, не наоборот
- **Декларативные таблицы + явный маппинг** — `to_domain()` / `to_dict()` для конвертации между слоями
- **Frozen dataclass для доменных сущностей** — иммутабельность по умолчанию
- **Literal + Values вместо Enum** — строковые значения без конвертации
- **Final[type] для констант** — запрет magic strings и magic values
