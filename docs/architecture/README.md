# Архитектура

Архитектурная документация проекта Astrology Server.

## Принципы

Архитектура основана на **DDD (Domain-Driven Design)** и **Hexagonal Architecture (Ports & Adapters)**, с опорой на подходы из [Cosmic Python](https://www.cosmicpython.com/).

- **SOLID** — с акцентом на Single Responsibility и Dependency Inversion
- **Доменная модель первична** — чистые Python dataclass-ы без зависимостей от инфраструктуры
- **Dependency Inversion** — инфраструктура зависит от домена, не наоборот
- **Слоистая архитектура** — чёткое разделение на слои с однонаправленными зависимостями
- **Модульная организация по доменам** — каждый модуль автономен и инкапсулирован
